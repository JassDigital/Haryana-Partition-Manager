# Haryana Partition Manager

> Desktop land-partition application for managing ownership shares, partition calculations, and Haryana land records.

## Overview

Haryana Partition Manager is a desktop application designed to support land-partition workflows involving ownership shares, land areas, and structured Haryana land-record information.

The project focuses on making complex ownership and partition calculations easier to inspect, organize, and work with through a practical desktop interface.

## Key Areas

- Ownership-share management
- Land-partition calculations
- Owner and share information
- Area-based calculations
- Structured land-record workflows
- Desktop data management
- Practical tools for Haryana land records

## Technology

- Python
- PySide6
- Desktop application architecture
